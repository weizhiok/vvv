# 统一订阅入口测试

## 直接 HTTP

安装时选择“直接 HTTP”。所有支持客户端填写安装完成后显示的同一个地址，例如：

```text
http://203.0.113.10:8443/Ab3dE7xQ
```

HTTP 模式不申请证书。它只适合测试，因为订阅内容中的 UUID 和密码会以明文传输。

## 直接 HTTPS

域名模式由 Caddy 自动申请公共证书；公网 IP 模式由 Certbot 申请 Let’s Encrypt IP 短期证书。HTTP 模式后期可在：

```text
vps → 订阅中心管理 → 开启 HTTPS 传输
```

进行事务式升级。申请或验证失败时继续保留原 HTTP；成功后原 HTTP 地址立即失效。域名证书签发或 Tunnel 公共主机名传播期间，安装器会等待并重复检查统一入口，不会因为第一次请求尚未成功就立即判定失败。

云备份开启后，加密包会包含 Certbot lineage、已部署证书、私钥、续期服务和部署脚本。恢复后脚本会校验证书有效期、IP SAN 以及证书与私钥是否匹配，再重新部署并重建续期服务。

## Cloudflare Tunnel

提前在 Cloudflare 创建 Tunnel 公共主机名，并把服务指向安装器使用的本地源站：

```text
http://127.0.0.1:8443
```

公开订阅地址使用标准 HTTPS 443，例如：

```text
https://v.example.com/Ab3dE7xQ
```

更换 VPS 时，在新服务器使用同一个 Tunnel 和相同订阅后缀，客户端地址不需要修改。订阅中心只有在配置明确处于 Tunnel 模式时才信任 `CF-Connecting-IP`；直连 HTTP/HTTPS 模式不会信任客户端自行提交的该请求头。

## 客户端识别调试

运行：

```text
vps → 订阅中心管理 → 客户端请求头识别调试
```

然后在目标客户端刷新统一订阅地址。SSH 会在 5 分钟内显示脱敏后的请求方法、来源地址、Host、User-Agent、Accept、转发协议和识别结果；Authorization、Cookie 和完整订阅后缀不会显示。监听结束或按 Ctrl+C 后，运行标记和临时请求日志会一起删除。

## 新客户端适配

只需更新 `core-src/client_adapters.py` 中的识别规则或渲染器，然后在服务器选择：

```text
vps → 订阅中心管理 → 更新客户端适配器
```

更新程序会执行语法检查、渲染器自检、原子替换和服务健康检查；失败自动回滚，不修改节点、主机注册信息或现有客户端格式。
